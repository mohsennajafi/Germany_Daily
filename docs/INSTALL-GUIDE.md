# راهنمای نصب German Daily

برنامه نیازی به فروشگاه ندارد. با چند لمس نصب می‌شود و بعد از نصب بدون اینترنت هم کار می‌کند.

## اندروید (Chrome / Edge / Samsung Internet)
1. لینک برنامه را در Chrome باز کنید (یا QR را با دوربین اسکن کنید).
2. دکمهٔ **«نصب با یک کلیک»** را بزنید و تأیید کنید.
   اگر دکمه نبود: منوی ⋮ ← **Install app** (نصب برنامه) یا **Add to Home screen**.
3. آیکن به صفحهٔ اصلی و لیست برنامه‌ها اضافه می‌شود.

## آیفون / آیپد (Safari)
1. لینک را در **Safari** باز کنید.
2. دکمهٔ **اشتراک‌گذاری** ⬆️ را بزنید.
3. **Add to Home Screen** ← **Add**.
4. برنامه تمام‌صفحه باز می‌شود. (در iOS 16.4 به بعد، Chrome و Edge هم از منوی اشتراک‌گذاری همین امکان را دارند.)

## کامپیوتر (Chrome / Edge)
آیکن نصب ⊕ در نوار آدرس ← **Install**. در Safari مک: File ← **Add to Dock**.

## به‌روزرسانی
برنامه خودش نسخهٔ جدید را پیدا می‌کند و پیام «به‌روزرسانی» می‌دهد؛ پیشرفت شما پاک نمی‌شود.

## حذف
اندروید: نگه داشتن آیکن ← Uninstall · iPhone: نگه داشتن آیکن ← Remove App · کامپیوتر: منوی برنامه ← Uninstall.
برای پاک‌کردن داده‌ها: برنامه ← تنظیمات ← «حذف همهٔ داده‌ها».
